# Changelog

## 0.1.1 - 2026-08-12

- Added explicit server-session deletion from the Android client.
- Clear now removes parsed server data instead of only resetting the screen.
- Re-uploading replaces and discards the previous temporary server session.
- Updated privacy messaging for the 30-minute backend session timeout.
- Builds directly from readable repository source.

## 0.1.0 — 2026-07-20

- First native Android client.
- Connected to FormaFlow v0.6 FastAPI endpoints.
- Added multi-file upload, dataset selection, column mapping, preview, and export.
- Added editable HTTPS backend URL and Render cold-start handling.
- Added explicit online-processing privacy notice.
